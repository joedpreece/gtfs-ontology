# GTFS Ontology

## Artifact
For the artifact, please download [`gtfs.ttl`](artifacts/gtfs.ttl).

To produce the artifact from scratch.
1. Clone this repository.
2. Set up your Python virtual environment.
3. Install the source code by running
    ```
    pip install .
    ```
4. Run the [generate_ontology.py](artifacts/generate_ontology.py) script.
